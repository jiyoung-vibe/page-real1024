# 완성본

수업 중에 정한 시각까지 단계를 못 마쳤을 때 넘어가는 단계별 완성본입니다. 넘어가는 것은 실패가 아닙니다.

| 폴더 | 언제 | 들어 있는 것 |
|---|---|---|
| `todo-1-html` | 1일차 HTML 단계 | index.html (HTML만, 버튼을 눌러도 아무 일 없음) |
| `todo-2-css` | 1일차 13:40까지 CSS를 못 마쳤을 때 | index.html, style.css |
| `todo-3-js` | 1일차 14:30까지 테스트를 못 마쳤을 때, 되돌리기가 꼬였을 때 | index.html, style.css, script.js |
| `page-1-css` | 2일차 11:25까지 포트폴리오 모양을 못 마쳤을 때 | index.html, style.css |
| `page-2-guestbook` | 2일차 13:50까지 방명록 연결을 못 마쳤을 때 | index.html, style.css, script.js (연습용 방명록에 연결됨) |

Claude Code에 보내는 요청 예:

```text
완성본/todo-2-css 폴더의 파일로 내 index.html과 style.css를 바꿔 줘. 제목은 지금 내 페이지 제목을 그대로 써 줘. 끝나면 커밋하고 푸시해 줘. 다른 파일은 건드리지 마.
```

`page-2-guestbook/script.js`에는 강사가 만든 「연습용 방명록」의 주소와 공개 키가 들어 있습니다. 공개 키는 페이지에 넣어도 되는 키이고, 규칙상 읽기·쓰기만 할 수 있습니다.
